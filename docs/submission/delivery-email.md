```
お世話になっております。チーム ムチュウです。
最終発表会に向けた納品物を提出いたします。

■ チーム名
ムチュウ

■ チームメンバー

■ プロダクト名
michinavi（ミチナビ）

■ プロダクトURL
https://michinavi.vercel.app

■ プレゼン動画URL
★ 動画のURLを記載（限定公開でも視聴できる状態にしてください）

■ プロダクトのコンセプト
災害時に本当に知りたいのは、天気でも避難所の場所でもなく「いま、目の前の道が
通れるか」です。その情報を持っているのは、現場にいる住民自身です。

みちナビは、住民が3タップで投稿した通行可否を地図に集め、そこから避難の判断
材料を返すアプリです。

AIは「避難してください」とは言いません。自宅にとどまる・徒歩・車という複数の
選択肢を根拠つきで並べ、「どうなったら切り替えるか」の基準まで示します。
決めるのは本人である、という立場を出力の形そのものに埋め込みました。

■ 機能紹介
1. 3タップ投稿
   「通れる／注意／通れない」を選ぶだけで投稿できます。災害時に長文は書けない
   ため、文章の入力は必須にしていません。写真を添えることもできます。

2. 地図と集約
   投稿を3色で地図に表示します。同じ地点に届いた複数の報告は1枚のカードに
   まとまり、代表的な状況が要約されます。同じ人の連投は1件に畳んで数えます。

3. 避難の選択肢と切り替え基準
   家族構成・車の有無・周辺の投稿状況から、複数の選択肢と「どうなったら
   切り替えるか」の基準を返します。

4. 避難所
   現在地から近い避難所を、ペット同行の可否・車いすで入れるかといった受入条件
   つきで返します。想定人数が定員を超えている場合は、代替の候補を提示します。

5. 家族の安否共有
   「避難済み」「支援が必要」などの状態を、同じ世帯の家族に共有します。
   アカウントを持たない家族（高齢の親など）の分は代理で登録できます。

6. 通報
   不適切な投稿を通報でき、運営側で非表示にできます。

■ デザイン紹介
・災害時に片手で、急いで操作する前提で設計しました。タップ領域は44px以上、
  主要なボタンは親指の届く画面下部に置いています。
・色は5色以内に絞りました（基本の青／通れる緑／注意の黄／通れない赤／文字の黒）。
・赤と緑が区別しにくい方に配慮し、色だけで意味を伝えないようにしています。
  地図の凡例は色と文字、通報済みは記号と文字を併記します。
・「まだ投稿がありません」で終わらせず、次に何をすればよいかを必ず書いています。

■ その他アピールポイント
1. AIに選択肢そのものを作らせていません
   候補はサーバ側が決めます（車のない世帯に「車」の選択肢が出ることは、仕組みの
   上で起こりません）。AIに任せるのは並び順・文面・切り替え基準だけで、出力は
   候補集合と突き合わせて検証し、1つでも合わなければ全部捨てて決定論的な選択肢に
   戻します。AIが落ちても選択肢は出ます。

2. 位置情報を丸めて保存しています
   投稿位置は約250mのメッシュに丸めてから保存し、生の座標はどこにも残しません。
   写真のExif（位置情報）はサーバ側で削除してから保存します。

3. 他人のデータが取れないことをテストで固定しています
   全テーブルで行レベルセキュリティを有効にし、他人のIDを指定しても0件になる
   ことを自動テストで担保しています。テーブルを追加したときに、公開してよいか
   の判断を通らずに公開されることがない作りにしました。

4. APIが落ちたときの案内を、エラー応答そのものに載せています
   画面ごとに書き忘れることがないよう、サーバ側の障害時は行政（倉敷市）と
   気象庁への案内を必ず添えて返します。

5. 自動テスト 215件（バックエンド166件 / フロントエンド49件）

■ 審査時の注意事項・動作環境
・推奨環境：スマートフォンの縦画面（Chrome / Safari の最新版）。
  PCの場合はブラウザの幅を狭めるか、開発者ツールのモバイル表示でご覧ください。
・ログインが必要です。下記の審査用アカウントをお使いください。

  メールアドレス：demo-sato@michinavi.example
  パスワード　　：demo-password-1234

  （家族が複数いる世帯の例です。ほかに demo-tanaka@michinavi.example、
    demo-suzuki@michinavi.example も同じパスワードでご利用いただけます）

・地図に表示される投稿、避難所、家族はすべて架空のデータです。実在の施設・
  人物ではありません。
・位置情報の許可を求める場面がありますが、許可しなくても操作できます。
★ 未実装の画面がある場合はここに明記する（例：◯◯画面は準備中です）
```
